# Initial takeaways:

- So far the general trend is showing that the default parameters don't make much of a difference. 
- I would say that so far the take away from this test would be that if there is known root disease in an area, using only default parameters for the WRDM will not produce accurate results. 
- It will be interesting to see if there is a similar trend with the Woods Creek data.

# Suggestions for improvements:
- More stringent default parameters for WRDM - Phellinus
- It would be nice to have some sort of way of automating the process for large data runs.
- The automation might show a range of expected statistical outcomes.
